8 basic concepts of programming in TLAC

Learn to program, one instruction at a time.

By Usmar A. Padow (amigojapan) · Author’s homepage

This lesson is for complete beginners. You can follow the instructions with the turtle board game, a coin, and paper. No programming experience is needed. Start with the order of instructions, then add one new idea at a time.

0. Following instructions in order

A program is a set of instructions. The computer follows them in a specified order, usually from top to bottom unless a condition, loop, or function changes the flow. The order matters: the computer does not rearrange your instructions to match what you meant.

Playing TLAC: use a small coin to mark the current instruction. Blue numbers such as 0001 tell you where you are. Yellow cards contain instructions; green cards contain comments for the reader.

This order means brushing your teeth, combing your hair, and then going to work. Now compare it with the same actions in a different order:

Here you leave for work before combing your hair. All three instructions are still present, but the sequence changes the result. This is why checking the order is one of the first steps in finding a programming mistake.

The original lesson also refers to this Richard Feynman lecture when discussing how literally computers follow instructions.

1. Variables

A variable is a name for a stored value. Think of a labeled box: the name tells you which box to use, and its current contents are the value. A variable can hold a number such as 5 or text such as “hello”. Text is called a string.

Names such as x or last_name are easy to use. In the examples, names do not contain spaces: last_name is one name, while “last name” is a phrase. Strings are shown in quotation marks to distinguish them from names and numbers. For example, last_name can store “Einstein”.

The kind of value matters. An identification number such as 123456789 can be written as a number, but “123-45-6789” is text because it includes separators. Choose a representation that preserves the information you need, including leading zeros when they matter.

A variable’s value can change. Setting x to 3 and later setting x to 5 replaces the old value; x now holds 5. This operation is called assignment. It records a value at a particular point in the program, rather than declaring a mathematical equation that must always be true.

Playing TLAC: write each variable’s name and current value on a separate sheet. Cross out the old value whenever an assignment changes it.

2. Statements and assignment

A statement is an instruction that performs a step of the program. Assignments, function calls, and conditions are examples. Follow these three assignments in order:

  1. Line 0001 sets x to 3.
  2. Line 0002 replaces that value with 5.
  3. Line 0003 reads the current x (5), adds 1, and stores 6 back in x.

In the notation x = x + 1, first calculate the expression on the right using the old value. Then put the result in the variable on the left. That destination is sometimes called the lvalue. The final value is 6; the instruction does not mean that a number is mathematically equal to itself plus one.

3. Conditions and blocks

A condition asks a question with a true or false answer. A block is a group of instructions that belongs together. If a condition is true, follow its block; if it is false, skip that block. The colored enclosure and indentation show which instructions belong to it.

Coordinates start at 0. X counts columns from the left and Y counts rows from the top. X=4 is the fifth column. “Move forward” moves the turtle one square in the direction of its head unless another distance is given.

Lines 0001–0003 are comments; they explain the program without moving anything. At line 0004, X is 4, so “X is greater than 3” is true. Enter the block and execute the forward move on line 0008. X stays 4; moving up changes Y from 9 to 8.

At line 0009, X is still 4, so “X is less than 3” is false. Skip the block, including the move on line 0012. Line 0013 then sets X to 2: move the turtle sideways to the third column without changing Y or its direction.

Line 0017 asks the same question again, but now X is 2. This time “X is less than 3” is true, so execute line 0021. The turtle moves up one square to X=2, Y=7. A condition uses the values at the moment it is checked.

Parameters: give a function the details it needs

A function name follows the same naming idea as a variable name. Some functions also accept parameters: values used for that call. “Move forward 5 squares” gives the movement function a distance of 5. A different call can give it another distance without redefining the movement instructions.

The display instructions in this example label and show the board after changing X. They help you see what happened; they do not lay eggs or turn the turtle. Changing X moves the turtle directly, whereas the forward instruction moves it in the direction of its head.

Returning from a function: when the function finishes, continue at the instruction after the call. A return instruction can finish the function early and can also send back a result. This example reaches the end of its body without an explicit return. A function used mainly for an action, rather than a returned value, is sometimes called a procedure.

A list stores several values in order. Each value is an item or element. An index tells you an item’s position. In these examples, counting begins at 0: the first item has index 0, the second has index 1, and so on. Arrays are another way to organize indexed values; here we use lists.

0. Seguir instrucciones en orden

Un programa es un conjunto de instrucciones. La computadora las sigue en un orden determinado, normalmente de arriba abajo, salvo que una condición, un bucle o una función cambie el recorrido. El orden importa: la computadora no reorganiza las instrucciones para hacer lo que tú querías decir.

Para jugar a TLAC: usa una moneda pequeña para señalar la instrucción actual. Los números azules, como 0001, indican dónde estás. Las tarjetas amarillas contienen instrucciones; las verdes, comentarios para quien lee.

Este orden significa cepillarte los dientes, peinarte y después ir al trabajo. Compáralo con las mismas acciones en otro orden:

Aquí sales hacia el trabajo antes de peinarte. Las tres instrucciones siguen presentes, pero la secuencia cambia el resultado. Por eso, revisar el orden es uno de los primeros pasos para encontrar un error de programación.

La lección original también remite a esta charla de Richard Feynman al hablar de cómo las computadoras siguen las instrucciones literalmente.

1. Variables

Una variable es un nombre para un valor guardado. Imagínala como una caja con etiqueta: el nombre indica qué caja usar y su contenido actual es el valor. Una variable puede guardar un número como 5 o texto como «hola». El texto se llama cadena.

Puedes usar nombres como x o last_name. En estos ejemplos los nombres no contienen espacios: last_name es un solo nombre, mientras que «last name» es una frase. Las cadenas se muestran entre comillas para distinguirlas de nombres y números. Por ejemplo, last_name puede guardar «Einstein».

El tipo de valor importa. Un identificador como 123456789 puede escribirse como número, pero «123-45-6789» es texto porque incluye separadores. Elige una representación que conserve la información necesaria, incluidos los ceros iniciales cuando sean importantes.

El valor de una variable puede cambiar. Asignar 3 a x y después asignarle 5 sustituye el valor anterior: ahora x guarda 5. Esta operación se llama asignación. Guarda un valor en un momento concreto del programa; no declara una ecuación matemática que deba ser cierta siempre.

Para jugar a TLAC: escribe los nombres de las variables y sus valores actuales en otra hoja. Tacha el valor anterior cuando una asignación lo cambie.

2. Instrucciones y asignación

Una instrucción o sentencia realiza un paso del programa. Las asignaciones, las llamadas a funciones y las condiciones son ejemplos. Sigue estas tres asignaciones en orden:

  1. La línea 0001 asigna 3 a x.
  2. La línea 0002 sustituye ese valor por 5.
  3. La línea 0003 lee el valor actual de x (5), suma 1 y guarda 6 en x.

En la notación x = x + 1, primero calcula la expresión de la derecha usando el valor anterior. Después guarda el resultado en la variable de la izquierda. Ese destino a veces se llama lvalue. El valor final es 6; la instrucción no afirma que un número sea matemáticamente igual a sí mismo más uno.

3. Condiciones y bloques

Una condición plantea una pregunta cuya respuesta es verdadera o falsa. Un bloque es un grupo de instrucciones que van juntas. Si la condición es verdadera, ejecuta su bloque; si es falsa, sáltalo. El recuadro de color y la sangría indican qué instrucciones pertenecen al bloque.

Las coordenadas empiezan en 0. X cuenta columnas desde la izquierda y Y cuenta filas desde arriba. X=4 es la quinta columna. «Avanzar» mueve la tortuga una casilla hacia donde mira su cabeza, salvo que se indique otra distancia.

Las líneas 0001–0003 son comentarios: explican el programa sin mover nada. En la línea 0004, X vale 4, así que «X es mayor que 3» es verdadero. Entra en el bloque y avanza en la línea 0008. X sigue en 4; al subir, Y cambia de 9 a 8.

En la línea 0009, X sigue valiendo 4, así que «X es menor que 3» es falso. Salta el bloque, incluido el movimiento de la línea 0012. Después, la línea 0013 asigna 2 a X: mueve la tortuga a la tercera columna sin cambiar Y ni su dirección.

La línea 0017 hace la misma pregunta, pero ahora X vale 2. Esta vez «X es menor que 3» es verdadero, así que ejecuta la línea 0021. La tortuga sube una casilla hasta X=2, Y=7. Una condición usa los valores que existen en el momento de comprobarla.

Una definición de función da un nombre a un grupo reutilizable de instrucciones. Una llamada a función pide al programa que realice ese grupo. Definir una función no ejecuta su cuerpo. Ya usamos llamadas en la rutina de la mañana:

Sigue su cuerpo y continúa después de la llamada. Luego asigna 5 a X y llámala en la línea 0025. Por último, asigna 8 a X y llámala en la línea 0029.

Parámetros: dar a una función los datos que necesita

El nombre de una función sigue la misma idea que el de una variable. Algunas funciones también aceptan parámetros: valores que se usan en esa llamada. «Avanzar 5 casillas» da a la función de movimiento una distancia de 5. Otra llamada puede darle otra distancia sin volver a definir las instrucciones.

Las instrucciones de mostrar de este ejemplo ponen un título y muestran el tablero después de cambiar X. Ayudan a ver lo ocurrido; no ponen huevos ni giran la tortuga. Cambiar X mueve la tortuga directamente, mientras que avanzar la mueve hacia donde mira su cabeza.

Volver de una función: cuando termina, continúa en la instrucción que sigue a la llamada. Una instrucción de retorno puede terminar la función antes y también devolver un resultado. Una lista guarda varios valores en orden. Cada valor es un elemento. Un índice indica su posición. Ahora usaremos una lista de frutas. Conservamos los valores guardados en inglés para que el orden alfabético y el resultado guardado coincidan en las tres versiones de la lección. La lista inicial contiene banana (banana), apple (manzana), peach (melocotón) y pear (pera).

ÍndiceValor guardado
0banana
1apple
2peach
3pear

La notación fruits[0] significa el elemento del índice 0: banana en la lista inicial. fruits[3] es el cuarto elemento: pear. Un índice identifica una posición, así que la palabra que ocupa esa posición puede cambiar al reorganizar la lista.

  1. Crear la lista en la línea 0002. La línea 0003 escribe el elemento del índice 3: pear. El siguiente bucle escribe todos los elementos en su orden actual.
  2. Invertirla en la línea 0012: pear, peach, apple, banana. Se cambia el orden, no las palabras.
  3. Ordenarla en la línea 0018: apple, banana, peach, pear. La ordenación coloca los nombres ingleses alfabéticamente.
  4. Añadir «appricot» al final en la línea 0022. Añadir al final conserva los elementos anteriores. Esa es la escritura del ejemplo original; la palabra habitual es «apricot» (albaricoque).
  5. Insertar «blueberry» (arándano) en el índice 2 en la línea 0024. Pasa a ser el tercer elemento; los posteriores se desplazan una posición a la derecha.
  6. Eliminar el índice 3 en la línea 0026. Es el cuarto elemento, que ahora es peach. La lista final es apple, banana, blueberry, pear, appricot.

Recuerda: las posiciones empiezan en 0. Leer un elemento no lo elimina. Invertir y ordenar cambian el orden; añadir, insertar y eliminar cambian el contenido o la longitud. Después de un cambio, usa el nuevo orden al interpretar un índice.

TLACで学ぶプログラミングの8つの基本概念

命令を1つずつ追いながら、プログラミングを学ぼう。

著者：Usmar A. Padow（amigojapan） · 著者のホームページ

初めてプログラミングを学ぶ人のための教材です。亀のボードゲームとコイン、紙を使って命令を追えます。プログラミングの経験は必要ありません。命令の順番から始め、考え方を1つずつ増やしていきましょう。

  1. 0. 命令を順番に実行する
  2. 1. 変数
  3. 2. 文と代入
  4. 3. 条件分岐とブロック
  5. 4. 手続きと関数
  6. 5. 入力と出力
  7. 6. 繰り返し
  8. 7. 配列とリスト

実行結果へのリンクを開くと、1ステップずつ確認できるデバッガーが表示されます。「次へ」「前へ」で現在の命令、変数、盤面や文字の出力を追えます。選んだ言語で実行結果も表示されます。

0. 命令を順番に実行する

プログラムは命令の集まりです。コンピューターは決められた順番で命令を実行します。条件分岐、繰り返し、関数で流れが変わらなければ、通常は上から下へ進みます。コンピューターが意図をくんで命令を並べ直してくれるわけではないので、順番が大切です。

TLACで遊ぶヒント：小さなコインで今の命令を指しましょう。0001などの青い番号で位置がわかります。黄色いカードは命令、緑のカードは読む人のためのコメントです。

この順番なら、歯を磨き、髪を整えてから仕事に行きます。同じ動作を別の順番にした場合と比べましょう。

こちらでは髪を整える前に仕事へ出発してしまいます。3つの命令は同じでも、順番が変わると結果も変わります。プログラムの間違いを探すときは、まず順番を確認しましょう。

元の教材では、コンピューターが命令をそのまま実行することについて、リチャード・ファインマンの講義も紹介しています。

1. 変数

変数は、保存した値につける名前です。ラベルつきの箱を思い浮かべてください。名前で使う箱を選び、中身が現在の値になります。5のような数や「こんにちは」のような文字を保存できます。文字の並びを文字列といいます。

xやlast_nameのような名前を使います。この例では名前に空白を入れません。last_nameは1つの名前ですが、「last name」は空白を含む表現です。文字列は引用符で囲み、名前や数と区別します。たとえばlast_nameに「Einstein」を保存できます。

値の表し方も大切です。123456789のような識別番号は数として書けますが、「123-45-6789」は区切りの記号を含む文字列です。先頭の0など、必要な情報が失われない表し方を選びます。

変数の値は変えられます。xを3にしてから5にすると、前の値が置き換わり、xは5になります。この操作が代入です。プログラムのその時点の値を保存する操作であり、いつでも成り立つ数学の等式を宣言するわけではありません。

TLACで遊ぶヒント：別の紙に変数名と現在の値を書きましょう。代入で値が変わったら、古い値を消して書き直します。

2. 文と代入

文は、プログラムの1つの処理を表す命令です。代入、関数呼び出し、条件分岐などがあります。次の3つの代入を順番に追いましょう。

  1. 0001行目でxを3にします。
  2. 0002行目でその値を5に置き換えます。
  3. 0003行目で現在のx（5）を読み、1を足して、6をxに保存します。

x = x + 1という書き方では、まず右側を古い値で計算し、結果を左側の変数へ保存します。この保存先を左辺値（lvalue）と呼ぶこともあります。最後の値は6です。ある数と、その数に1を足したものが数学的に等しいという意味ではありません。

3. 条件分岐とブロック

条件は、正しいかどうかを調べる問いです。ブロックは、ひとまとまりの命令です。条件が成り立てば中を実行し、成り立たなければ飛ばします。色つきの囲みと字下げで、どの命令がまとまりに属するかがわかります。

座標は0から数えます。Xは左からの列、Yは上からの行です。X=4は左から5列目です。「前に進む」は、距離の指定がなければ亀の頭が向いている方向に1マス進めます。

0001〜0003行目は説明のためのコメントなので、何も動かしません。0004行目ではXが4のため「Xは3より大きい」が成り立ちます。ブロックに入り、0008行目で前に進みます。上へ進むのでXは4のまま、Yが9から8になります。

0009行目でもXは4なので「Xは3より小さい」は成り立ちません。0012行目の移動も含め、ブロックを飛ばします。0013行目でXを2にするので、Yと向きは変えずに左から3列目へ移動します。

0017行目で同じ問いを調べ直します。今はXが2なので「Xは3より小さい」が成り立ち、0021行目を実行します。1マス上へ進み、X=2、Y=7になります。条件は、調べたその時点の値を使います。

4. 手続きと関数

関数の定義は、何度も使える命令のまとまりに名前をつけます。関数の呼び出しは、そのまとまりを実行するよう頼みます。定義するだけでは中の命令は実行しません。朝の行動の例でも、関数を呼び出していました。

次は、4個の卵を正方形に並べる動作を定義します。「卵を置く」は亀のいるマスに印をつけます。「右に回る」は位置を変えず、時計回りに90度回転します。これらはTLACに用意されている動作です。正方形を作る関数は、プログラムを書く人が新しく定義する動作です。

0003〜0017行目で関数を定義しています。メインの命令は0018行目からです。Xを0にして盤面を表示し、0021行目で関数を呼びます。関数の中を実行したら、呼び出した命令の次へ戻ります。次はXを5にして0025行目で呼び、最後にXを8にして0029行目で呼びます。

1回呼ぶたびに2×2の正方形に卵を4個置き、上向きで終わります。3回の呼び出しで3つの正方形、合計12マスに卵が置かれます。同じ命令を3回書き写す代わりに、1回定義して使い回すので、短く、読みやすく、変更しやすくなります。

引数：関数に必要な情報を渡す

関数には変数と同じように名前をつけます。関数に渡す値を引数といいます。「5マス前に進む」では、移動する関数に距離5を渡します。別の呼び出しで別の距離を渡しても、移動の手順を定義し直す必要はありません。

この例の表示命令は、Xを変えた後に見出しと盤面を表示して、何が起きたかを見やすくします。卵を置いたり、亀を回したりはしません。Xの変更は横の位置を直接変え、「前に進む」は頭の向きに移動します。

関数から戻る：関数が終わると、呼び出した命令の次へ進みます。「戻る」という命令で途中で終えることも、結果の値を返すこともできます。この例は明示的な戻る命令を使わず、中の命令の最後まで実行して戻ります。値を返すよりも動作を行うための関数を、手続きと呼ぶこともあります。

5. 入力と出力

出力：結果を見せる

出力は、プログラムが作る情報や、見える結果です。TLACでは盤面の変化や紙に書いた内容が出力になります。次はとても短いプログラムです。

亀は上向きです。5マス進むとYが9から4になり、Xは4のままです。この盤面の変化が出力です。移動した内容や移動番号を文字で表示することもできます。

入力：プレイヤーから情報を受け取る

入力は、プログラムが受け取る情報です。TLACでは、プレイヤーが頼まれたとおりに駒を動かすことで入力できます。プログラムはその位置を読み、覚えておくことができます。

  1. 0004行目でいつもの開始位置X=4、Y=9にします。空白の0002行目では何もしません。
  2. 0005行目で左上の隅に置くよう頼みます。0006行目は、その操作の例としてX=0、Y=0へ移動します。
  3. 0007、0008行目で現在のXとYをsavedXとsavedYに保存します。その時点の値をコピーします。
  4. 0009、0010行目で右下の隅X=9、Y=9への移動を頼み、操作の例を示します。
  5. 0011行目でsavedX、savedYの位置へ戻します。この例ではX=0、Y=0に戻ります。

操作例の命令は、保存された実行結果でプレイヤーの動きを示すためのものです。紙で遊ぶときは、人が操作します。別の場所を選んだり間違えたりした場合、保存するのは期待した位置ではなく、実際に読み取った位置です。1人がコンピューター役、もう1人が駒を操作するゲームなどに使えます。

6. 繰り返し

繰り返し（ループ）は、命令のまとまりを何度も実行します。似た命令を何回も書く代わりに、使う値や終了条件を指定します。「何を繰り返すか」「何が変わるか」「いつ終わるか」を考えましょう。

7. 配列とリスト

リストは複数の値を順番に保存します。1つずつの値を要素といい、添字（インデックス）で位置を表します。この例では0から数えるので、最初の要素は添字0、2番目は添字1です。配列も添字で値を扱う方法ですが、ここではリストを使います。

各要素について：亀の命令リストを使う
